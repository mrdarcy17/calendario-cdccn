# calendario-cdccn

Es un calendario donde se irá registrando los días que interactúe y una pequeña nota de la interacción.

| Carpeta / archivo | Contenido |
|---|---|
| [`hu.md`](hu.md) | Historias de usuario |
| [`casos-de-uso.md`](casos-de-uso.md) | Casos de uso |
| [`media/`](media/) | Imágenes de referencia del diseño |
| [`maquetación/`](maquetación/) | Maqueta visual (solo diseño, nada funcional) |
| [`esquema/`](esquema/) | Estructura del archivo de datos JSON, su esquema y un ejemplo |
| [`web/`](web/) | Web local funcional ([instrucciones](web/README.md)) |

## Empezar

```fish
cd web
pnpm install
pnpm dev     # http://localhost:5180
```
